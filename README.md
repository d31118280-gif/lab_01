# **Лабораторная работа 1. «Компьютерная лексикография, терминологические базы (TBX) и Translation Memory (TMX) в Smartcat»**

**ФИО студента:** Шишкова Дарья Игоревна 
**Группа:** ИНФА-221 
**Вариант:** 14 (предметная область: *"Строительство, архитектура и BIM-технологии"*)

**Цель работы:** научиться программно обрабатывать стандарты обмена терминологическими данными (TBX) и памятью переводов (TMX), реализовать поиск нечётких совпадений (Fuzzy Match) и подстановку терминов глоссария, экспортировать результат в CAT-систему Smartcat.

**Ход работы:**
1. Создание и работа с терминологической базой TBX
2. Создание и обработка памяти переводов TMX
3. Использование метрик Levenshtein Ratio, Token Sort Ratio
4. Работа с различными типами совпадений (ICE, Fuzzy и т.д.)
5. Автоматическая подстановка терминов глоссария в исходный текст

Была создана терминологическая база из 100 терминов и память переводов, состоящая из 100 единиц для перевода. Автотесты пройдены успешно. С основными файлами было проверено 3 сценария совпадения: ICE, Fuzzy и No Match. Всё работает успешно.
